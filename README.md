### About

A compatibility layer between Flywheel model rendering and Distant Horizons block model rendering allowing for blocks and models rendered by Flywheel like those from Create and Vanillin to properly render in LODs


### Features
- Quad merging to lower quad counts on large models like large water wheels
- Extra fixes for Create and Copycats+ for the following blocks
  - Peculiar Bell and Haunted Bell
  - Fluid Pipes
  - Fluid Tanks
  - Harvesters
  - Mechanical Rollers
  - Mechanical Saws
  - Andesite, Copper, Glass, Brass, and Train doors
  - Spouts
  - Steam Engine
  - Steam Whistle
  - Straight Train rails
  - Belts
  - Copycat+ Blocks (only render the copycat default texture)
